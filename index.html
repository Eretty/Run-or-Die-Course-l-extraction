Ordres de mission

Trois étapes. Aucune garantie.

Le but n'est pas de nettoyer la ville. Il est de rester en mouvement assez longtemps pour sortir vivant.

01 / SURVIVRE

Garde tes distances

La population est concentrée en ville. Les zombies sont fragiles, mais une majorité peut sprinter : un mauvais détour peut transformer une rue en piège.

02 / LOCALISER

Trouve le signal

Fouille et récupère l'équipement nécessaire à l'extraction. Le signal est actif dès le début ; aucun délai de préparation ni relais à construire n'est configuré.

03 / EXTRAIRE

Tiens jusqu'au bout

Rejoins la zone d'extraction choisie aléatoirement. L'événement dure trois heures en jeu : prépare ton itinéraire et garde une issue de secours.

Installation du preset

Prêt à lancer la partie.

Télécharge le fichier de configuration Sandbox, place-le dans le dossier des presets de Project Zomboid, puis sélectionne-le avant de créer ton monde.

01 / TÉLÉCHARGER

Récupère le fichier

Clique sur le bouton de téléchargement et conserve run-or-die-extraction.cfg sans modifier son extension.

02 / INSTALLER

Place-le au bon endroit

Ferme le jeu, puis copie le fichier dans Zomboid/Sandbox Presets/ de ton dossier utilisateur. Sous Windows : %UserProfile%\Zomboid\Sandbox Presets\. Sous Linux : ~/Zomboid/Sandbox Presets/. Crée le dossier s'il n'existe pas.

03 / EN JEU

Sélectionne le preset

Relance Project Zomboid, démarre une partie en Solo avec le mode Sandbox, puis choisis le preset « Run or Die » avant de créer le monde.

Important : ce fichier configure les paramètres Sandbox ; il n'installe pas les mods. Abonne-toi aux mods requis sur le Workshop et active-les pour la partie. Le fichier doit se trouver à la racine du dépôt sous le nom exact run-or-die-extraction.cfg pour que le bouton de téléchargement fonctionne sur GitHub Pages.
